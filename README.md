# 哈希最后5个数字｜每段双选形态优化系统

## 新预测方式
系统仍然从哈希末尾提取最后5个数字，并拆分为：
- 前三
- 中三
- 后三

但下一期预测不再只给每段1个形态，而是每段给出排名最高的2个形态。

例如：
- 前三预测：对子、杂六
- 实际前三开出对子或杂六，均算前三命中

中三、后三规则相同。

## 整套命中
同一期必须：
- 前三命中其两个预测之一
- 中三命中其两个预测之一
- 后三命中其两个预测之一

三段全部命中，才算整套方案命中。

## 分类
- 豹子
- 顺子
- 对子
- 杂六
- 半顺

## 功能
- 最近最多220期
- 每5秒自动刷新
- 10套动态方案
- 每段预测2个形态
- 冻结20/30/50期中奖率
- 自动选择最优方案
- 下一期开奖前冻结
- 开奖后固定中/未中
- 投注金额、赔率和盈利计算
